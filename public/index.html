AgentMesh의 데이터 처리 원칙을 안내합니다.

시행일 · 최종 수정일 2026년 10월 29일

핵심 안내

AgentMesh는 사용자가 연결한 Google Workspace 문서를 AI 에이전트와 함께 읽고 검토·편집하기 위한 도구입니다. 요청된 협업 기능을 위해 데이터를 처리하며, Google 사용자 데이터를 판매하거나 광고에 사용하지 않습니다.

접근하는 데이터이용 목적공유와 AI보관과 보호철회와 삭제문의

01 적용 대상과 운영자

이 방침은 baecha가 운영하는 AgentMesh MCP 서버, 협업 웹 UI 및 이 안내 사이트에 적용됩니다. Google, AI 서비스 제공자 및 Cloudflare가 자체 서비스에서 처리하는 정보에는 각 제공자의 개인정보처리방침도 적용됩니다.

02 접근·처리하는 데이터

  • Google 인증 정보: 사용자가 동의한 API 접근을 유지하기 위한 OAuth 액세스 토큰, 갱신 토큰 및 부여된 권한 범위. Google 계정 비밀번호는 수집하지 않습니다.
  • Google Workspace 데이터: 요청된 Google Drive 파일의 ID, 이름, 유형, 수정 시각, 접근 가능 여부와 같은 메타데이터, Google Docs 본문·탭·리비전, 지정된 Sheets 셀 데이터 및 Slides 텍스트 등 도구 실행에 필요한 내용.
  • 협업 기록: 프로젝트, 참여 에이전트 식별자, 등록 파일 정보, 검토·답글·작업, 편집 제안의 원문·변경문과 실행 결과, 활동 이력.
  • 접속·인증 정보: 웹 로그인 세션, MCP 인증·인가 정보 및 장애 대응에 필요한 접속·오류 기록. 호스팅·보안 제공자가 IP 주소와 요청 정보를 처리할 수 있습니다.

실제 접근 범위는 동의한 Google OAuth 권한과 사용 중인 서버 설정에 따릅니다. 전체 Drive 권한을 연결한 경우, 연결 계정이 접근할 수 있는 파일의 검색·읽기 및 허용된 편집 작업에 사용할 수 있습니다. API 권한이 있다는 이유로 모든 파일을 자동 수집하지 않습니다.

03 이용 목적

데이터는 사용자가 요청한 파일 검색·읽기, 문서 검토, 편집 제안과 실행, 에이전트 간 작업 조율, 권한 확인, 변경 이력·충돌 관리 및 서비스 보안·장애 대응에 사용합니다. 편집은 제공되는 도구와 권한·승인 절차에 따라 수행됩니다.

Google 사용자 데이터를 판매하거나 타깃 광고, 데이터 중개 또는 신용평가에 이용하지 않습니다.

04 에이전트·외부 서비스와의 공유

MCP 도구의 응답에는 사용자가 요청한 문서 내용과 메타데이터가 포함될 수 있으며, 연결된 AI 클라이언트와 해당 제공자에게 전달됩니다. 프로젝트에 접근 가능한 다른 에이전트는 공유된 협업 기록을 읽을 수 있습니다. 사용자는 연결할 클라이언트와 공유할 프로젝트·문서를 신중하게 선택해야 합니다.

Google은 인증과 Workspace API 요청을, Cloudflare는 웹 트래픽 전달과 호스팅·보안을 처리합니다. 데이터는 제공자 인프라가 위치한 국가에서 처리될 수 있습니다. 연결된 AI 제공자의 대화 보관·학습 설정은 해당 서비스의 정책과 사용자 설정을 확인해야 합니다.

운영자의 데이터 접근은 사용자가 요청한 지원, 보안·장애 대응, 법적 의무 이행 등에 필요한 범위로 제한합니다. 공개 저장소나 이 정책 사이트에 사용자의 문서 내용·인증 정보를 게시하지 않습니다.

05 Google API 데이터의 제한적 이용

AgentMesh가 Google API로부터 받은 정보의 이용 및 다른 앱으로의 전송은 Google API Services User Data Policy와 그 안의 Limited Use 요구사항을 준수합니다. 해당 데이터는 사용자에게 제공되는 요청된 기능에 필요한 범위에서 사용·전달하며, 범용 AI·머신러닝 모델의 개발·개선·학습에 사용하지 않습니다.

AgentMesh's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

06 보관 기간과 보호 조치

OAuth 토큰과 협업 데이터베이스는 운영자 서버에 저장됩니다. 파일 메타데이터, 리뷰, 작업, 편집 제안 및 감사 이력에는 문서의 일부 내용이 포함될 수 있습니다. 읽기 응답은 요청 처리와 클라이언트 전달에 사용되며, 문서 전체를 별도 데이터베이스에 일괄 복제하는 기능은 제공하지 않습니다.

서비스 이용과 협업 이력 유지에 필요한 동안 데이터를 보관합니다. 현재 자동 삭제 기한은 설정되어 있지 않습니다. 연결 해제만으로 기존 협업 기록이 자동 삭제되지는 않으며, 삭제를 원하면 운영자에게 요청할 수 있습니다. 법적 의무나 보안 사고 조사에 필요한 기록은 해당 목적에 필요한 기간 보관할 수 있습니다.

HTTPS, 인증·프로젝트 접근 제어, 토큰 파일 권한 제한 등의 보호 조치를 사용합니다. 오류 진단에 토큰·키 값이나 Google의 원본 오류 본문을 출력하지 않도록 처리합니다.

07 접근 철회·열람·삭제 요청

Google 계정의 서드 파티 연결 관리에서 AgentMesh의 접근 권한을 철회할 수 있습니다. 철회 후에는 새 Google API 접근이 중단되며, 다시 연결하려면 동의가 필요합니다.

저장된 OAuth 토큰, 프로젝트 데이터 및 문서에서 파생된 협업 기록의 열람·정정·삭제는 아래 연락 경로로 요청해 주세요. 운영자는 요청자의 권한과 다른 참여자의 권리, 보존 의무를 확인한 뒤 처리하고 결과를 안내합니다. AI 클라이언트에 이미 전달된 대화·문서 데이터는 해당 제공자의 삭제 절차도 별도로 이용해야 합니다. AgentMesh 기록 삭제가 원본 Google 문서 삭제를 의미하지는 않습니다.

08 이 사이트와 쿠키

이 개인정보처리방침 사이트는 정적 페이지이며 자체 광고, 분석 스크립트, 로그인 폼 또는 쿠키를 추가하지 않습니다. Cloudflare는 페이지 제공과 보안 목적으로 접속 정보를 처리할 수 있습니다. AgentMesh 협업 웹 UI는 로그인 유지에 필요한 세션 쿠키를 별도로 사용합니다.
